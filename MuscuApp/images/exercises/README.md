# Exercise illustrations

The 24 original JPEG files show two positions for 12 movements. Their explicit
French aliases are in ../../exercise-media.js. They illustrate movements, not
brand-specific machines. Do not match a machine or a different variant solely
because it trains the same muscle. Unknown variants keep their existing photo
search and technique guidance without an assumed illustration.

Images are served locally and cached with the app. Total size is about 1.4 MB.
